  RTXStub/shaders/Include/SeraphicRT/BlazerEndSky.hlsl

The original GLSL was ported to HLSL (Shader Model 6.5) and modified for the
SeraphicRT Minecraft RTX End sky:
  - GLSL-to-HLSL matrix orientation;
  - guarded reciprocal and power operations;
  - shared disk/dust samples;
  - bounded HDR (scene-linear) output;
  - a stereographic upper-sky projection;
  - stable star brightness and wrapped spherical star cells.
The original Java shaderpack was not edited.
