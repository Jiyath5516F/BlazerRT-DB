# BlazerBake alpha 0.0.2: first release

## Commands
### check: see what a bake would do, nothing changes
### bake: bake the pack, with a backup of every changed file
### clear: take a bake back out of the pack

## Baking
### Mob, item and held-block PBR from your texture sets
### Inventory icons stay solid
### Animated block textures with one MER or normal map for all frames
### Finer relief for high-resolution mob textures
### Finer relief on items
### A height guessed from brightness when a texture set has none
### Subsurface scattering for the textures you pick
### Bake only mobs, only items or only blocks
### Fully metal item pixels if you want them
### Grass sides and other tint masks are left alone
### Glass and other see-through textures are skipped
### See-through mob and item textures only when you ask

## Backups and clearing
### Automatic backup in Documents\BlazerBake backups
### Finds your Documents folder even when Windows moved it
### Clear a bake exactly with the backup
### Clear without a backup takes the bake data out

### One exe for Windows, nothing to install
